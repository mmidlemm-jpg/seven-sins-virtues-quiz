# 七宗罪 vs 七美德 · 14维人性光谱测试

## 在线体验

启用 GitHub Pages 后访问：  
**https://mmidlemm-jpg.github.io/seven-sins-virtues-quiz/**

## 如何启用 GitHub Pages

1. 打开仓库 Settings → Pages
2. Build and deployment → Source 选择 **Deploy from a branch**
3. Branch 选 `main`，Folder 选 `/ (root)`
4. Save，等待1-2分钟即可访问
